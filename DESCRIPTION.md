# Zhige Flutter Template

一个高质量、易于使用的 Flutter 项目模板，旨在帮助开发者快速构建出色的跨平台应用程序。

A high-quality, easy-to-use Flutter project template designed to help developers quickly build outstanding cross-platform applications.

## 主要特性 / Key Features

- 使用 Get 框架进行状态管理 / Using Get framework for state management
- Isar 数据库提供高性能本地存储 / Isar database for high-performance local storage
- 完整的 GitHub OAuth 登录示例 / Complete GitHub OAuth login example
- 多语言支持 / Multi-language support
- 主题切换 / Theme switching
- 模块化设计 / Modular design
- 完整的 TODO 应用示例 / Complete TODO app example

## 技术栈 / Tech Stack

- Flutter 3.7.2+
- Get 4.6.6
- Isar 3.1.0+
- Dio 5.4.0
- Flutter Web Auth 2.2.1+
